# 📄 AI Resume Matcher — ATS Scoring & Semantic Compatibility Engine

> **Applicant Tracking System (ATS) optimization tool** that extracts resume text from PDF documents, computes semantic match scores against job descriptions, and highlights missing keywords.

---

## 📌 Engineering Highlights

* **Automated PDF Parsing**: Extracts text, skills, and experience sections from complex multi-column PDF layouts.
* **Semantic Compatibility Scoring**: TF-IDF vectorization and cosine similarity scoring to accurately rank candidate fit.
* **Actionable ATS Recommendations**: Highlights critical keywords missing in the resume to boost automated screening pass rates.

---

## 🚀 Quick Start

```bash
git clone https://github.com/sakshirautela/AI-Powered-Resume-Match.git
cd AI-Powered-Resume-Match
pip install -r requirements.txt
python app.py
```
